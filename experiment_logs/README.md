# 实验日志目录

本目录用于记录“视觉伪图像驱动的时序专家路由”项目的每一步实验。

## 全局追踪

本目录需要维护一个全局追踪文件：

```text
实验日志总览.md
```

每新增一个实验日志，都要在 `实验日志总览.md` 中登记一行，包括：

- 时间
- 阶段
- 日志文件
- 实验目的
- 当前状态
- 核心结果
- 下一步

## 单个实验日志命名

每个实验都需要单独写日志，建议命名细化到分钟：

```text
YYYY-MM-DD_HHMM_<stage>_<short-name>.md
```

示例：

```text
2026-06-05_1730_stage0_quitobench_data_audit.md
2026-06-06_0915_stage1_imageization_smoke.md
```

日志建议结构：

```markdown
# 实验名称

## 1. 实验目的

## 2. 实验计划

## 3. 执行命令

## 4. 输入数据与配置

## 5. 实验结果

## 6. 问题与观察

## 7. 结论

## 8. 下一步计划
```

要求：

- 每一步实验都要记录计划、执行、结果、结论和下一步。
- 失败实验也必须记录。
- 如果使用随机抽样，需要记录 seed 和抽样策略。
- 如果修改了计划，需要说明修改原因。
- 每个小日志完成后，需要同步更新 `实验日志总览.md`。
- 文档尽可能使用中文。
