# 研究视觉模型在时序建模中的可迁移性与功能定位：方案完善

## 1. 核心定位

本课题建议聚焦一个清晰命题：

> 预训练视觉模型不一定要直接承担时序预测任务，而可以作为“结构先验提取器/样本级路由器”，从内生伪图像中识别周期、趋势、突变、频域结构、递归结构等全局模式，并据此调度更适合的时序预测专家。

这个定位比“把 ViT 改造成预测器”更稳妥，原因有三点：

1. VisionTS 已证明视觉 MAE/ViT 表征可以迁移到单变量时序预测，但其主要方式是把预测重写为图像重建，仍存在多变量、概率预测、可解释路由等扩展空间。
2. TimeFuse 表明不同预测模型在不同样本上各有所长，样本级自适应融合比单一模型更合理。
3. ReGuider 表明用强时序基础模型的中间表征做表示级监督，比只蒸馏输出更能保留动态模式。

因此，本课题的创新点可以表述为：

> 构建一个“视觉结构先验驱动的时序专家路由框架”，系统研究内生伪图像表征、视觉表征对齐、专家选择/融合和功能定位。

## 2. 相关文献脉络

### 2.1 时序转图像与视觉模型迁移

- Wang 和 Oates 早期提出 GASF/GADF/MTF，把时间序列编码为图像，用 CNN 处理分类和插补任务。
- TimesNet 从多周期角度把 1D 时序重排为 2D 张量，建模周期内变化和周期间变化，是“周期截断重排”方案的直接理论支撑。
- VisionTS 使用预训练视觉 MAE 做零样本/少量微调时序预测，支持“视觉模型具有可迁移结构先验”的基本假设。
- Harnessing Vision Models for Time Series Analysis 综述了时序图像编码和视觉模型建模方式，可以作为文献综述主线。
- LDM4TS 使用多视角视觉表征和潜空间扩散做预测，说明多种伪图像组合有潜力捕捉互补结构。

### 2.2 时序预测专家与强基线

- DLinear/LTSF-Linear 是必须纳入的强简单基线，避免方案只在复杂模型之间比较。
- PatchTST 通过 patch 和 channel-independent 设计提升长时预测能力，适合作为 Transformer 专家。
- iTransformer 将变量维作为 token，适合多变量依赖强的数据。
- TimeMixer 用多尺度分解和 MLP mixing 建模复杂变化，适合作为多尺度专家。
- Time-MoE、Mixture-of-Linear-Experts 等 MoE 工作支持专家化建模，但多数路由仍直接来自时序表征，本课题差异在于“视觉结构先验路由”。

### 2.3 表征监督、原型库与自适应融合

- ReGuider 用预训练时序基础模型中间 embedding 监督目标模型 encoder，可借鉴为 ViT 的时序语义微调目标。
- TimeFuse 用 meta-features 预测样本级模型融合权重，可作为下游融合结构的直接参照。
- Aurora 的 Prototype Bank 可简化为“结构原型库”，不必采用流匹配生成；可将 prototype 作为路由先验、检索增强或辅助解释。
- Quito/QuitoBench 提供大规模同源业务流量时序和评价实例，适合作为训练“时序标签/结构标签”的数据来源。

## 3. 研究问题

建议把原始问题细化为 4 个可验证问题：

1. **RQ1：哪些内生伪图像最适合作为 ViT 的结构输入？**
   比较周期重排图、GAF/GADF、MTF、RP、STFT/CWT scalogram、多视角通道堆叠。

2. **RQ2：ViT 在框架中最有效的功能是什么？**
   比较直接预测器、并行特征分支、专家路由器、专家权重融合器、结构原型检索器。

3. **RQ3：视觉表征是否真的学到了时序语义？**
   用结构标签预测、表征对齐、路由可解释性和跨数据集泛化验证，而不仅看最终 MSE/MAE。

4. **RQ4：视觉路由是否优于传统 meta-feature 路由？**
   对比手工统计特征路由、时序 encoder 路由、视觉 encoder 路由、视觉+统计联合路由。

## 4. 模型方案

### 4.1 基础框架

输入单变量或多变量序列 `X in R^{L x C}`，预测 `Y in R^{H x C}`。

建议先从单变量启动，降低路由与图像编码复杂度：

1. 每条序列窗口经过标准化和多视角伪图像编码。
2. ViT/MAE 编码伪图像，输出结构向量 `z_v`。
3. `z_v` 进入 router，得到专家权重 `w = softmax(g(z_v))`。
4. 多个专家分别预测 `y_k`。
5. 输出为加权融合：`y_hat = sum_k w_k * y_k`。

专家池建议第一版使用：

- `DLinear`：趋势/季节性强且简单可预测时的低复杂度专家。
- `PatchTST`：局部 patch 和长上下文专家。
- `TimeMixer` 或 `TimesNet`：多尺度/多周期专家。
- 可选 `N-HiTS` 或统计模型：增强非深度/分解类专家覆盖。

### 4.2 伪图像设计

第一阶段建议固定 5 类：

| 视图 | 捕捉结构 | 适合数据 | 注意点 |
| --- | --- | --- | --- |
| 周期重排 2D | 周期内/周期间变化 | 强周期、日/周节律 | 周期估计错误会引入噪声 |
| GASF/GADF | 全局两两时间相关 | 平滑趋势、形状模式 | 对归一化敏感 |
| RP | 状态递归和非线性动力学 | 混沌、突变、重复状态 | 阈值/嵌入维选择影响大 |
| MTF | 离散状态转移 | 分段状态、负载等级变化 | 分箱数需要调参 |
| STFT/CWT | 时间-频率局部结构 | 多频率、突发波动 | 分辨率和尺度选择影响成本 |

组合方式建议分三档消融：

1. 单视图：每次只输入一种伪图像。
2. RGB 通道堆叠：选 3 个互补视图堆为 3 通道，兼容 ImageNet 预训练 ViT。
3. 多视图 token 融合：每个视图单独编码，使用 view-attention 融合，成本较高但解释性更强。

第一版推荐：

`周期重排 + GASF + CWT` 作为 RGB 三通道，因为三者分别对应周期结构、全局相关、频域结构。

## 5. ViT 微调目标

你的三部分损失是合理的，但建议重新命名并明确权重：

`L = L_tag + lambda_align * L_align + lambda_rec * L_rec + lambda_route * L_route`

其中：

1. `L_tag`：结构标签预测损失。
   标签可来自 Quito 分析工具或自动特征计算，例如 seasonality strength、trend strength、forecastability、entropy、acf1、spikiness、dominant period、frequency type。

2. `L_align`：时序教师表征对齐。
   冻结一个时序基础模型或强 encoder，抽取中间层 embedding，与 ViT CLS token 或 pooled tokens 对齐。可用 MSE、cosine loss 或 projection 后 InfoNCE。

3. `L_rec`：掩码重建。
   随机 mask 原始序列片段或伪图像 patch，要求重建完整序列或重建伪图像。第一版建议重建“标准化后的原始序列”，这样更贴近时序语义。

4. `L_route`：专家路由监督。
   离线训练专家后，在验证样本上记录每个专家的 oracle rank 或 soft target，训练 router 预测专家权重。这样比完全端到端路由更稳定。

训练流程建议：

1. 训练/准备专家池。
2. 对训练集窗口生成专家预测，得到每个样本的专家误差分布。
3. 预训练/微调 ViT，学习结构标签、教师表征和重建。
4. 冻结或半冻结 ViT，训练 router 预测专家权重。
5. 联合微调 router 和专家输出头，低学习率更新 ViT。

## 6. 数据与标签

### 6.1 数据集

第一阶段建议使用标准长时预测数据集：

- ETTm1/ETTm2/ETTh1/ETTh2
- Electricity
- Traffic
- Weather
- Exchange
- ILI

第二阶段使用 Quito/QuitoBench：

- 优点：同源大规模、业务垂直丰富、适合学习结构标签和跨 regime 泛化。
- 用法：不要一开始全量训练，先抽样构建 10k-100k 窗口的结构标签预训练集。

### 6.2 自动结构标签

建议为每个窗口计算：

- 趋势强度、季节强度、主周期、周期置信度
- ACF1、PACF summaries
- spectral entropy、dominant frequency ratio
- stationarity proxy，例如 ADF/KPSS 或 rolling mean variance drift
- spikiness、level shift、missingness、outlier ratio
- forecastability 或基于简单模型误差的难度分层

这些标签有两个作用：

1. 作为 ViT 的辅助监督。
2. 作为解释 router 行为的中间变量。

## 7. 实验设计

### 7.1 主实验

评价任务：

- 长时预测：`L in {96, 192, 336, 720}`，`H in {96, 192, 336, 720}`。
- 单变量先做，随后扩展多变量。

指标：

- MSE、MAE
- sMAPE 或 MASE，用于跨尺度数据比较
- router oracle gap：当前融合误差与每样本最佳专家误差的差距
- expert utilization entropy：是否塌缩到单专家
- routing-label agreement：路由选择和结构标签的一致性

### 7.2 对照组

必须包含：

1. 单专家：DLinear、PatchTST、TimeMixer/TimesNet。
2. 均匀平均 ensemble。
3. 验证集全局最优固定权重 ensemble。
4. TimeFuse 风格统计 meta-feature router。
5. 时序 encoder router。
6. 视觉 ViT router。
7. 视觉+统计联合 router。

### 7.3 消融实验

伪图像：

- 周期重排 / GAF / RP / MTF / CWT 单视图
- RGB 堆叠组合
- 多视图 attention

ViT：

- ImageNet 预训练冻结
- ImageNet 预训练微调
- MAE 预训练微调
- 从零训练 ViT

损失：

- 只 `L_tag`
- `L_tag + L_align`
- `L_tag + L_rec`
- 三者全开
- 加入 `L_route`

路由：

- hard top-1 专家
- soft top-k 专家
- 全专家加权
- 带 entropy/load-balancing 正则

## 8. 扩展版本：历史增强 RAG 分支

RAG 分支建议不要在第一版加入，否则变量过多。第二阶段可设计为：

1. 用 ViT 结构向量 `z_v` 和统计特征共同检索历史相似窗口。
2. 检索库保存 `(past window, future window, structure labels, best expert id)`。
3. 返回 top-k 历史 future patterns 或 prototype residual。
4. 将检索结果作为 router 额外输入，或作为预测残差校正项。

可检验问题：

- 结构相似检索是否比 raw Euclidean/DTW 检索更有效？
- 检索样本的 best expert 分布是否能辅助当前专家路由？
- RAG 对低 forecastability 或 regime shift 样本是否更有用？

## 9. 主要风险与应对

1. **伪图像可能引入人为纹理，ViT 学到的是编码器伪迹。**
   应对：加入 permutation、周期扰动、归一化扰动测试；比较统计 router。

2. **专家路由可能塌缩到最强专家。**
   应对：oracle soft label、load-balancing、top-k routing、分 regime 汇报结果。

3. **最终指标提升有限。**
   应对：把贡献扩展到功能定位和解释：视觉模块是否更擅长识别结构、是否降低 oracle gap、是否提升跨数据集泛化。

4. **ViT 微调成本高。**
   应对：先冻结 ViT 只训练投影层/router；再用 LoRA 或最后几层微调。

5. **多变量场景复杂。**
   应对：先做 channel-independent 单变量窗口；第二阶段再研究变量间图像编码或 iTransformer 专家。

## 10. 建议的最小可行原型

MVP 不要一开始做完整 MoE。建议 4 周版本：

1. 数据：ETTm1、Electricity、Weather。
2. 伪图像：周期重排、GAF、CWT。
3. ViT：冻结 ImageNet ViT 或 MAE，输出 CLS embedding。
4. 专家：DLinear、PatchTST、TimeMixer。
5. Router：MLP soft weights。
6. 监督：先用 oracle expert error 训练 `L_route`，暂不做 `L_align/L_rec`。
7. 对照：单专家、平均 ensemble、统计特征 router。

如果 MVP 证明视觉 router 能降低 oracle gap，再进入完整多任务微调。
