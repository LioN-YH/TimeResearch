## 1. 当前研究目标

核心问题：

> 视觉模块能否从通道独立的 sample-channel 历史窗口中学习跨 `history_len`、`pred_len` 和数据源都尽量稳定的时序结构先验，并用该先验驱动异构时序专家的连续自适应融合？

当前实验路线分为两条：

### 路线 1：能力验证线

目标：

> 验证视觉时序结构 embedding 是否能迁移到异构专家连续融合任务，并相对统计 proxy、固定 ensemble 和 best fixed expert 降低 oracle gap。

特点：

- 不使用 TSF 标签训练 router/gate。
- 使用 sample-channel window 作为视觉模块输入粒度。
- 可以按 TSF cell 报告结果，但 official cluster 只作解释分层。
- 输出窗口索引、轻量 proxy、专家预测缓存、soft oracle target 和 continuous gate baseline。
- 重点指标包括 oracle gap、routing entropy、expert utilization entropy、top-k oracle coverage 和在线推理 latency。

### 路线 2：结构解释线

目标：

> 解释视觉结构先验在哪些官方 TSF cell、通道异质性模式、窗口长度和预测 horizon 上有效，并验证 few-shot、跨 cell 和跨数据源泛化能力。

路线 2 分为：

- 2A：QuitoBench TSF cell 分层与专家画像。
- 2B：TSF 监督视觉编码。
- 2C：few-shot router adaptation。
- 2D：leave-one-cell-out 泛化。

4. 下一步做 **Stage 1.0：窗口索引与配置注册表**。

Stage 1.0 目标：

> 建立后续所有 sample-channel 缓存的统一主键，避免不同 `history_len`、`pred_len`、split、图像化配置和专家预测结果互相混淆。

Stage 1.0 建议输出：

```text
outputs/vision_ts_routing/window_registry/<config_hash>/window_index.csv

outputs/vision_ts_routing/window_registry/<config_hash>/manifest.json
```

窗口索引每一行建议对应一个 sample-channel 预测样本，至少包含：

- `subset`
- `item_id`
- `channel`
- `start_idx`
- `history_len`
- `pred_len`
- `period`

5. Stage 1.0 之后再做 **Stage 1.1：sample-channel light proxy 预计算**。

Stage 1.1 只计算在线可复现的轻量统计 meta-features，不做 full STL：

- mean / std / median / IQR
- min / max / amplitude
- last value
- slope
- recent volatility
- lag-1 ACF / period-lag ACF
- simple spectral entropy
- dominant frequency strength
- missing ratio
- simple trend / seasonality proxy

6. 仍不要直接实现 router。

正式 router/gate 需要等以下接口稳定后再做：

- Stage 1.0 window registry
- Stage 1.1 light proxy
- Stage 1.2 伪图像协议 smoke test
- Stage 1.4 异构专家预测缓存

当前推荐的主线是：

```text
Stage 1.0 window registry
-> Stage 1.1 sample-channel light proxy
-> Stage 1.2 imageization protocol smoke test
-> Stage 1.3 visual encoder representation/pretraining
-> Stage 1.4 heterogeneous expert prediction cache
-> Stage 1.5 continuous gate fusion validation
```

关键约束：

- 视觉模块输入粒度是 sample-channel history window。
- official cluster 是 item 级解释标签，只用于分层报告和结构解释。
- Stage 0.7 通道级 STL 只用于通道异质性分析和伪图像设计参考。
- router/gate 的主要训练目标来自同一 sample-channel/horizon 下的异构专家误差和 soft oracle。
- 在线路径不使用 full STL，只使用轻量 proxy、视觉 embedding 和 top-k soft routing。
